# veierblat.github.io

Perséinlech Neuseeland-2026-Websäit.

## Date vun der App iwwerhuelen

D'NewZealand2026-App erstellt iwwer **Websäit exportéieren** en Dossier mat:

- `data/trip-data.json`
- `data/roadroute.geojson`
- `images/`

Fir d'Websäit ze aktualiséieren, ginn dës zwee Dossieren an
`newzealand/` iwwerholl. Privat Dokumenter, Sync-Dateien,
Buchungsnummeren, Präisser a Reservatiounsnotize sinn net am Export.
